# Campus Utility Desk

## About the Project

Campus Utility Desk is a simple Python command-line application designed to help students perform basic calculations, convert distances, and choose suitable study activities.

## Features

- **Quick Calculator:** Performs addition, subtraction, multiplication, and division.
- **Unit Converter:** Converts kilometres to miles and miles to kilometres.
- **Study Sprint Checker:** Suggests study activities based on available time and energy level.
- **Input Validation:** Handles invalid entries and prevents division by zero.

## Technologies Used

- Python 3
- VS Code
- Command-Line Interface (CLI)

## How to Run the Project

1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the command:

   `python campus_utility_desk.py`

   If that does not work on Windows, try:

   `py campus_utility_desk.py`
