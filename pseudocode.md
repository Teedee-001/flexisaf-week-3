# Campus Utility Desk — Pseudocode

1. START the program.
2. Display a welcome message.
3. REPEAT:
   - Display the main menu.
   - Ask the user to select an option.

4. IF the user selects Quick Calculator:
   - Ask for two numbers and an operator.
   - Perform the selected calculation.
   - Check for division by zero.
   - Display the result or an error message.

5. ELSE IF the user selects Unit Converter:
   - Display the conversion options.
   - Ask the user to choose a conversion.
   - Ask for the distance.
   - Reject invalid choices or negative distances.
   - Calculate and display the converted distance.

6. ELSE IF the user selects Study Sprint Checker:
   - Ask how many minutes the user can study.
   - Validate the input.
   - Ask the user to select an energy level.
   - Suggest a suitable study activity.
   - Display the recommendation.

7. ELSE IF the user selects Exit:
   - Display a goodbye message.
   - STOP the program.

8. ELSE:
   - Display an invalid menu choice message.

9. Return to the main menu when appropriate.
